# @erp/ui

Componentes de interfaz compartidos entre **React Native** (apps/mobile) y **React Native Web** (apps/web).

> Estado: pendiente. Se implementa en la **Fase 16** (Frontend web + mobile), cuando existan los flujos
> de negocio que definan los componentes reales necesarios (tablas, formularios, menús, tarjetas de KPI).

Reglas:

- Solo componentes sin lógica de negocio.
- Tipados con TypeScript estricto.
- Accesibilidad (labels, contraste, tamaño táctil) desde el primer componente.
